## Problem

Businesses needed a reliable way to run WhatsApp campaigns without wrestling with Meta's raw Marketing API directly.

## Solution

Built the Node.js/Express backend, integrated the Meta Marketing API with secure token generation, and mapped external Ad Account and Page IDs into internal databases.

## Outcome

Shipped a production integration layer supporting programmatic campaign creation and performance insights.

## Learnings

Learned to handle OAuth flows, third-party API authentication, and idempotent onboarding at scale.
