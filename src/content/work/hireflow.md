## Problem

Recruiters needed one platform to track applications, coordinate interviews, and manage candidates across roles.

## Solution

Built 20+ REST APIs in Spring Boot with an indexed PostgreSQL schema for fast candidate search and filtering across recruitment stages.

## Outcome

Delivered an end-to-end platform with role-based, JWT-secured access for recruiters, admins, and candidates.

## Learnings

Deepened experience in schema design, indexing strategy, and structuring auth across multiple user roles.
